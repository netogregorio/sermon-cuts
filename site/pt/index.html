Instalar — escolha seu caminho

De zero a primeiro corte em menos de 5 minutos.

Três jeitos de entrar. O primeiro se você tem terminal (nativo em macOS, Linux e Windows), o segundo se você vive num editor de IA, o terceiro se preferir não instalar deps no host.

🟢

Um comando no terminal

Recomendado. Nativo em macOS, Linux e Windows — sem WSL.

curl -fsSL https://onetogregorio.github.io/sermon-cuts/install.sh | bash
winget install Python.Python.3.12 Git.Git
git clone https://github.com/onetogregorio/sermon-cuts %USERPROFILE%\code\sermon-cuts
%USERPROFILE%\code\sermon-cuts\scripts\install.bat
🟡

Através do seu editor de IA

Claude Code, Cursor, Codex, Cline, Aider — qualquer um com acesso ao terminal. 

Instala a skill Sermon Cuts (https://github.com/onetogregorio/sermon-cuts) na minha máquina. Me guia pelos passos abaixo e para se algum falhar:

1. Detecta meu sistema (macOS, Linux ou Windows). No macOS usa Homebrew (instala se faltar), no Linux usa apt/dnf/pacman, no Windows usa winget.
2. Instala as dependências de sistema: ffmpeg (com libass), yt-dlp, Python 3.12+, Git. Os comandos mudam por OS — usa o certo.
3. Clona o repo pra ~/code/sermon-cuts no Unix ou %USERPROFILE%\code\sermon-cuts no Windows (ou me pergunta onde colocar).
4. Roda scripts/install.sh no macOS/Linux ou scripts\install.bat no Windows — ele cria o venv, instala requirements e wires a skill em ~/.claude/skills/sermon-cuts/.
5. Me pergunta se quero transcrição melhor via Groq Whisper. Se sim, abre https://console.groq.com/keys, pede pra eu colar a chave e adiciona GROQ_API_KEY=... no ~/.env (ou %USERPROFILE%\.env no Windows).
6. Me pergunta se quero a fonte da marca Outfit Black (https://fonts.google.com/specimen/Outfit). Se sim, baixa e instala na minha pasta de fontes.
7. Roda ./scripts/pipeline.sh doctor (Unix) ou scripts\pipeline.bat doctor (Windows) pra confirmar que a skill está pronta.
8. Me dá um exemplo de uma linha de como cortar meu primeiro sermão.

Reporta sucesso ou o passo que falhou no final.

Docker

Builds reproduzíveis, CI, ou onde você preferir não instalar deps no host.

docker run --rm \

  -e GROQ_API_KEY=$GROQ_API_KEY \

O que tem dentro

Feito pra mensagens que merecem mais que uma noite corrida de domingo.

▶

Reenquadre vertical inteligente

Face tracking do MediaPipe centraliza o pregador no frame 1080×1920 com pan suave de 2.5s. Sem cortes bruscos.

Aa

Legenda brand-style

3 presets built-in (Arial Black em qualquer máquina, Helvetica Bold pra macOS, Outfit Black pra display de marca). 3-4 palavras por linha, sentence case, posicionada acima da barra UI do Reels/TikTok.

✦

IA propõe, você escolhe

Cada corte precisa de hook, desenvolvimento e conclusão, 25-60s. Não pode terminar em "porque…" ou "mas…". Ranqueados por arco narrativo — você aprova antes de qualquer render começar.

♪

Áudio balanceado por loudness

loudnorm EBU R128 do ffmpeg pra -14 LUFS com true-peak limiter em -1.5 dBTP — padrão do Instagram e TikTok, sem clipping.

⌘

Um comando, ponta a ponta

./scripts/pipeline.sh <url> faz ingest, transcrição, detecção de pausas com VAD, scrub do SRT e render limpo com barra de progresso ao vivo.

⊞

Multiplataforma, nativo

macOS, Linux e Windows — todos nativos, sem WSL. O pipeline inteiro é Python portável; pipeline.bat no Windows espelha pipeline.sh flag por flag.

★

Qualidade de entrega numa flag

--quality max --codec hevc exporta HEVC 10-bit Main 10 com denoise + sharpen. --llm-scrub pega erros de legenda que heurística não pega. --target shorts afina pra cada plataforma.

⎈

Várias marcas, uma instalação

Joga um style.yaml na pasta de qualquer sermão ou passa --preset NOME pra override pontual. Corta pra vários ministérios ou canais sem mexer no global.

⎋

Seguro pro pastor por padrão

O provider padrão mantém seu áudio local (auto-legenda do YouTube só consulta a URL). Modelos MediaPipe pré-baixados na instalação — primeiro render funciona offline.

Como funciona

Quatro passos. Em menos de 10 minutos da URL ao upload.

  1. 1

    Joga uma URL

    Link do YouTube ou um .mp4 local. Funciona em vídeos de 30 a 60 minutos.

  2. 2

    O pipeline transcreve e analisa

    Transcrição word-level (grátis via legendas auto do YouTube ou premium via Groq Whisper) + detecção de pausas pra cortes nunca dividirem palavras.

  3. 3

    Seu editor de IA propõe 10 cortes

    Cada um com tema, hook, desenvolvimento, conclusão e score de coerência. Você escolhe quais renderizar — tipicamente 5 a 8.

  4. 4

    Cortes saem verticais

    1080×1920, com face tracking, legenda brand-style queimada, áudio a -14 LUFS. Joga direto no Reels/TikTok/Shorts.
